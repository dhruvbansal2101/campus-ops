# 🚀 CampusOps

A modern campus issue reporting and tracking system built with Next.js.

---

## ✨ Features

- 📊 Dashboard with quick issue reporting
- 📝 Report issues (Cafeteria, WiFi, Infrastructure, etc.)
- 📍 Live tracking timeline
- 👤 Profile section
- 🎨 Clean UI with hover interactions
- ⚡ Pre-selection from dashboard to report page

---

## 🛠️ Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Lucide Icons

---

## 📦 Getting Started (Run Locally)

### 1. Clone the repo

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Run the development server

```bash
npm run dev
```

---

### 4. Open in browser

```
http://localhost:3000
```

---

## 🌐 Deployment

This project is deployed using Vercel.

To deploy your own:

1. Go to https://vercel.com
2. Import the GitHub repo
3. Click Deploy
